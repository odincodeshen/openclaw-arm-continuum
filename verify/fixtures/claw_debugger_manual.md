# CLAW debugger reference (sample)

## Section 1

The CLAW.Option.ResetDelay setting controls how the debugger behaves on the target. Its default value is 7 msec. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.

## Section 2

The CLAW.Option.TraceDepth setting controls how the debugger behaves on the target. Its default value is 64 frames. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.

## Section 3

The CLAW.Option.WatchPeriod setting controls how the debugger behaves on the target. Its default value is 250 msec. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.

## Section 4

The CLAW.Option.CacheLines setting controls how the debugger behaves on the target. Its default value is 512 lines. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.

## Section 5

The CLAW.Option.ProbeVoltage setting controls how the debugger behaves on the target. Its default value is 1.8 V. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.

## Section 6

The CLAW.Option.LinkSpeed setting controls how the debugger behaves on the target. Its default value is 40 MHz. Change it only when the board documentation asks for it; the debugger checks the value when the session starts and reports an error if it is out of range.
